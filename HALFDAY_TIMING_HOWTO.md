# Half-Day Leave Timing - How It Works

## Important: Half-Day is NOT a Separate Leave Type!

**Half-day timing is a flexible option for ANY existing leave type.**

You don't select "Half-Day Leave" from the dropdown. Instead:

1. Select your normal leave type: **Sick Leave**, **Casual Leave**, **Earned Leave**, etc.
2. Choose the **same date** for both Start Date and End Date (single-day leave)
3. The **half-day timing fields will appear automatically**

---

## Step-by-Step Guide for Employees

### How to Request a Half-Day Leave with Custom Timing

#### Step 1: Go to Leave Management
Navigate to: **Leave** → **Leave Management**

#### Step 2: Select Leave Type
Choose from the dropdown:
- Sick Leave
- Casual Leave
- Earned Leaves
- Menstrual Leave (if applicable)
- Unpaid Leaves

#### Step 3: Select the SAME Date for Start and End
- **Start Date:** Example: 2026-09-20
- **End Date:** Example: 2026-09-20 (SAME DATE)

**⚠️ IMPORTANT:** As soon as you select the same date for both fields, the half-day timing section will appear!

#### Step 4: Choose Your Half-Day Timing
You'll see a new section with:

**Option A: Use Quick Presets**
- Click **"Morning (9 AM - 1 PM)"** button
- OR click **"Afternoon (2 PM - 6 PM)"** button

**Option B: Enter Custom Times**
- Start Time: Enter time (e.g., 10:00)
- End Time: Enter time (e.g., 14:00)

#### Step 5: Enter Reason and Submit
- Fill in the reason for your leave
- Click **"Submit Request"**

## Troubleshooting

### Problem: "I don't see the half-day timing fields!"

**Solution Checklist:**
1. ✅ Did you select the **same date** for Start Date and End Date?
2. ✅ Are both dates filled in? (timing only shows after BOTH dates are selected)
3. ✅ Try refreshing the page and try again

### Problem: "Start time must be before end time" error

**Solution:**
- Make sure Start Time is earlier than End Time
- Example: ✅ 09:00 to 13:00 (VALID)
- Example: ❌ 14:00 to 09:00 (INVALID)

### Problem: "Invalid time format" error

**Solution:**
- Use 24-hour format: HH:MM
- Examples: 09:00, 14:30, 16:45
- NOT: 9am, 2:30pm, 1630

## FAQ

### Q: Can I take half-day for multi-day leaves?
**A:** No. Half-day timing is only for single-day leaves (when start and end date are the same).

### Q: Do I need to select "Half-Day" from the leave type dropdown?
**A:** No! There is no "Half-Day" in the dropdown. Select your normal leave type (Sick, Casual, etc.) and then specify the timing.

### Q: What if I want a full-day leave?
**A:** Simply don't fill in the timing fields. They're optional! If you leave timing blank, it's treated as a full-day leave.

### Q: Can I use any custom timing?
**A:** Yes! You can enter any start and end time you need, not just the presets.

### Q: Does the half-day timing affect my leave balance?
**A:** The timing is for record-keeping. It shows when you'll be absent. The leave still counts as 1 day in your balance.

### Q: Can I edit the timing after submitting?
**A:** Currently, no. You need to cancel the request and submit a new one. Contact HR if you need changes.
